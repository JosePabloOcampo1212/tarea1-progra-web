# Base Web Forms (.NET Framework 4.8)

1. Abra `Tarea1PrograWeb.sln` en Visual Studio y pulse F5 para comprobar que corre.
2. Renombre el proyecto desde el Explorador de soluciones (clic derecho, Cambiar nombre) si quiere otro nombre, y cambie el namespace.
3. Agregar paginas: clic derecho en el proyecto, Agregar, Nuevo elemento, "Web Form con pagina maestra", y elija `Site.Master`.
4. Ya incluye: `Site.Master` con ScriptManager (EnablePageMethods), jQuery 3.7.1 completo, `Scripts/comun.js` (Mesa.ajax) y `sessionState InProc` en Web.config.
5. Cree el repositorio Git antes de escribir codigo.
